Omar Call Tracker

Omar Call Tracker (the "Omar Call Review" desktop app) is a private tool built for a single business. It reads sales-call transcripts from a Google Drive folder the user chooses, uses AI to score each call against the business's coaching rubric, and keeps a searchable log of calls and follow-ups.

The app is not offered to the public. Access is limited to the business owner.
